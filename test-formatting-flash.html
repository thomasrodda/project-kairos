Testing Formatting Toolbar Flash Fix

Test Instructions

Manual Test Steps:

  1. Open the application in the iframe below
  2. Type some text in a block
  3. Select some text by dragging
  4. Press Ctrl+B (or Cmd+B on Mac) to apply bold
  5. Watch the formatting toolbar - it should NOT flash purple on all icons
  6. Only the Bold button should become active (purple)
  7. Try with Ctrl+I and Ctrl+U as well

Expected Behavior:

  • When using keyboard shortcuts, only the relevant button should change state
  • Other buttons should remain in their current state (no flash)
  • The toolbar should not flicker or jump
  • When clicking toolbar buttons, behavior should be the same as before

Fix Details

What was fixed:

  • Added check to prevent active format updates during formatting operations
  • Toolbar now maintains its state while keyboard shortcuts are being processed
  • After formatting completes, the state is updated to reflect the new formatting
  • This prevents the brief flash where all buttons lose their active state
